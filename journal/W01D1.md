## Why does a task need and `id` when it already has `text`? Give the specific scenario where text alone fails

Each task needs an `id` because that gives each task a unique number incase there are two tasks with the same wording.

For example, if I have two tasks named "feed dog", each task has a unique `id` and if I tick one of them, the other one will stay visible becasue that `id` hasn't been ticked.
