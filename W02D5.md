# W02D5 — Modules, tests, deploy, and the bug hunt

**Goal:** the code is split into modules, a few unit tests pass, the app is live at a
public URL, and you've found a planted bug by hand.

**Time budget:** ~95 min hands-on · ~25 min self-review + bug hunt · ~15 min journal

> **Claude Code may write code today.** Keep the diffs small. Read every one. Do not
> accept a change you can't explain out loud. A failing test today is a question to
> diagnose, not a red thing to make green.

---

## 1. Extract the pure functions into a module (~30 min)

Create `src/todo.js`. Move in the three pure functions you designed on `W02D3` and
export them:

```js
export function addTask(tasks, text, id) {
  return [...tasks, { id, text, done: false }];
}

export function toggle(tasks, id) {
  return tasks.map(t => t.id === id ? { ...t, done: !t.done } : t);
}

export function remove(tasks, id) {
  return tasks.filter(t => t.id !== id);
}
```

In `app.js`, import them and use them in the handlers instead of the inline
`push` / `find` / `filter`:

```js
import { addTask, toggle, remove } from './todo.js';
// ...
tasks = addTask(tasks, text, nextId++);
tasks = toggle(tasks, id);
tasks = remove(tasks, id);
```

Change the script tag to a module:

```html
<script type="module" src="app.js"></script>
```

**Modules don't load from `file://`.** Run a local server from `src/`:

```bash
cd src && python3 -m http.server 8000
```

Open `http://localhost:8000`. This is Claude Code's cue to help if the import wiring
fights you — but you read the diff.

## 2. Tests (~40 min)

Create `tests/test.js`:

```js
import assert from 'node:assert/strict';
import { addTask, toggle, remove } from '../src/todo.js';

let passed = 0;
function test(name, fn) { fn(); passed++; console.log('ok -', name); }

test('addTask appends one task with done:false', () => {
  const out = addTask([], 'buy milk', 1);
  assert.equal(out.length, 1);
  assert.equal(out[0].text, 'buy milk');
  assert.equal(out[0].done, false);
});

test('addTask does not mutate its input', () => {
  const input = [];
  addTask(input, 'x', 1);
  assert.equal(input.length, 0);
});

test('toggle flips done for the matching id only', () => {
  const out = toggle([{ id: 1, text: 'a', done: false }, { id: 2, text: 'b', done: false }], 1);
  assert.equal(out[0].done, true);
  assert.equal(out[1].done, false);
});

test('remove drops the task with that id', () => {
  const out = remove([{ id: 1, text: 'a', done: false }, { id: 2, text: 'b', done: false }], 1);
  assert.equal(out.length, 1);
  assert.equal(out[0].id, 2);
});

console.log(`\n${passed} passed`);
```

Run it:

```bash
node tests/test.js
```

At least three must pass. Add one more test of your own — a case you actually care
about.

### green -> red -> green

Once they pass: deliberately break `toggle` in `src/todo.js` (flip `!t.done` to
`t.done`). Run the tests — watch which one fails and read the assertion message. Then
put it back and confirm green. That's the loop: a red test names a real difference
between what you expected and what the code does.

## 3. Deploy (~20 min)

1. Create a repo on GitHub, push `main`.
2. Settings -> Pages -> Source: `main`, folder: `/root` or `/src` — pick one. If you
   pick `/root`, move `src/*` to the repo root first and fix the paths.
3. Wait for the build, open the public URL **on your phone**. Add a task there.

## 4. Week 2 self-review and the bug hunt (~25 min)

- **Demo, adversarially:** double-click Add fast, delete every task, refresh with an
  empty list, add a 500-character task, toggle everything.
- **Diffs:** `git log -p` since `W02D1`, re-read every change.
- **`broken/`:** open `broken/index.html`, `broken/app.js`, `broken/styles.css`. Serve
  that folder (`cd broken && python3 -m http.server 8001`) and use the app. There is
  **one planted bug**. Find it and fix it **with AI off**. The fix is one line. Write
  in `journal/J10.md`: the symptom you saw, how you tracked it down, and the one-line
  fix. See `broken/README.md` for the exact repro steps.
