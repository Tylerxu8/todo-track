# W01D5 — JavaScript: add a task

**Goal:** typing a task and submitting the form adds it to the visible list. Plus the
Week 1 self-review.

**Time budget:** ~70 min hands-on · ~20 min self-review · ~15 min journal · ~15 min buffer

> Last AI-free day. From `W02D1` you may ask Claude to *explain* — never to write.

---

## 1. Remove the sample row (~5 min)

Delete the temporary `<li>` from inside `<ul id="list">`. JavaScript generates rows
now. The `<ul>` is empty again in the HTML.

## 2. Load a script (~10 min)

Create `src/app.js`. Load it at the end of `<head>` or `<body>`:

```html
<script src="app.js" defer></script>
```

`defer` means the browser parses the HTML first, then runs the script — so your
elements exist when the code looks for them.

## 3. Grab the elements (~15 min)

```js
const form = document.querySelector('#new-task');
const input = document.querySelector('#task-input');
const list = document.querySelector('#list');

console.log(form, input, list); // none of these should be null
```

Open the console. If any is `null`, your selector or your `id` is wrong. Fix it before
moving on.

## 4. Handle submit (~35 min)

```js
form.addEventListener('submit', (event) => {
  event.preventDefault();               // stop the page reloading
  const text = input.value.trim();
  if (text === '') return;              // ignore empty / spaces-only

  // YOU WRITE THIS PART:
  // 1. make an <li>
  // 2. give it a checkbox, a <span> with `text`, and a
  //    <button type="button" class="delete">Delete</button>
  // 3. append the <li> to `list`

  input.value = '';
  input.focus();
});
```

Tools you need for the part you write: `document.createElement('li')`,
`document.createElement('span')`, setting `.textContent`, and `list.appendChild(li)`.
Build the same row shape you had as the sample on `W01D2`.

> **Foundations note — events.** `addEventListener('submit', fn)` registers `fn` to
> run every time the form is submitted. `fn` receives an *event object*;
> `event.preventDefault()` cancels the browser's default response to that event —
> here, navigating/reloading. Full detail: `sidelines/events.md`.

## 5. Test by hand (~15 min)

- Add several tasks — each appears as a new row.
- Submit with the box empty — nothing happens, no blank row.
- Submit `"   spaces   "` — added as `spaces`, trimmed.
- After each add the box is empty and focused.
- The page never reloads on submit.

**The checkbox and delete button don't do anything yet.** That's `W02D1`. Don't wire
them today.
