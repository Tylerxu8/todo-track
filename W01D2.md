# W01D2 — Semantic HTML: the form and the list

**Goal:** the real markup for the input form and the (empty) task list, written with
semantic elements. No CSS and no JavaScript today.

**Time budget:** ~85 min hands-on · ~15 min journal · ~20 min buffer

> Still AI-free. If you get stuck, read [MDN on HTML
> forms](https://developer.mozilla.org/en-US/docs/Learn/Forms) — not a chatbot.

---

## 1. The form (~30 min)

Inside `<body>`, below the `<h1>`, add:

```html
<form id="new-task">
  <label for="task-input">New task</label>
  <input type="text" id="task-input" name="task" autocomplete="off">
  <button type="submit">Add</button>
</form>
```

Understand each choice:

- **`<form>`**, not a bare input and button. A form gives you submit-on-Enter for
  free and a single `submit` event to listen for on `W01D5`.
- **`<label for="task-input">`** paired with **`id="task-input"`** — clicking the
  label focuses the input, and screen readers announce them together.
- **`type="submit"`** on the button — that's what fires the form's `submit` event.

## 2. The list (~20 min)

Below the form:

```html
<ul id="list"></ul>
```

Empty is correct. JavaScript fills it on `W01D5`. An empty `<ul>` is valid HTML.

## 3. A temporary sample row (~20 min)

So you have something to style on `W01D4`, put one hardcoded row inside the `<ul>`:

```html
<ul id="list">
  <li>
    <input type="checkbox">
    <span>Buy milk</span>
    <button type="button" class="delete">Delete</button>
  </li>
</ul>
```

This row is scaffolding. It stays through `W01D4` (CSS needs it) and you delete it on
`W01D5` when JavaScript starts generating rows. Note that in your journal so you don't
forget it's there.

## 4. Check it (~15 min)

- Open `src/index.html`. Type in the box, press Enter — the page reloads (no handler
  yet). That reload is exactly what `event.preventDefault()` will stop on `W01D5`.
- Tab through the page with the keyboard only. Input, then button, then the checkbox,
  then delete. Order should feel natural.
- Confirm: exactly one `<h1>`; the label's `for` matches the input's `id`.

---

## What "done" looks like for W01D2

- The form has a labelled text input and a submit button.
- `<ul id="list">` contains exactly one temporary sample `<li>` with a checkbox, a
  text span, and a delete button.
- The page is keyboard-navigable in a sensible order.
- No CSS, no JS, no `<script>` tag yet.
