## 2. Read (~40 min)

1. `sidelines/pure-functions.md` in this repo. Read it twice.
2. [MDN —
   `JSON.stringify`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/JSON/stringify)
   and
   [`JSON.parse`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/JSON/parse).
   Read the intro and the first example of each.

The two ideas:

- A **pure function** takes its inputs as arguments, returns a result, and changes
  nothing else — no DOM, no `localStorage`, no reassigning the caller's array. Same
  inputs always give the same output. It's the easiest kind of code to test, because
  a test is just "call it with X, check you got Y."
- **JSON** is a text format for data. `JSON.stringify(value)` turns an array/object
  into a string; `JSON.parse(text)` turns that string back into an array/object. It's
  how your `tasks` array becomes something `localStorage` can hold.

## 3. Exercise — design your three operations as pure functions (~25 min)

On paper. Do **not** put these in the app — that's Day 5. Right now "add a task" in
your code is tangled up with `render()`, `nextId`, and the DOM. Strip all that away
and write just the data transformation.

Write out the signature and body of each, by hand:

```
addTask(tasks, text, id)
  -> returns a NEW array: every task in `tasks`, plus { id, text, done: false } on the end
  -> does NOT push onto `tasks`
  -> hint: [...tasks, { id, text, done: false }]

toggle(tasks, id)
  -> returns a NEW array: same tasks, but the one whose id matches has done flipped
  -> does NOT modify any task object in place
  -> hint: tasks.map(t => t.id === id ? { ...t, done: !t.done } : t)

remove(tasks, id)
  -> returns a NEW array: every task except the one whose id matches
  -> hint: tasks.filter(t => t.id !== id)
```

For each one, write two sentences under it: *what would make this impure?* (e.g. "if it
called `render()`", "if it did `tasks.push(...)`", "if it read from `document`").

## 4. Predict, then check — the JSON round trip (~20 min)

For each line below, **write your prediction in `journal/W02D3.md` first**. Then open

```js
// prediction: is `done` still there? still false? still a boolean?

// prediction: what happens?

JSON.parse(null)
// prediction: error, or a value?
```
